# わたしのタスク

日本語のシンプルなタスク管理アプリ。追加・完了切り替え・削除・絞り込みに対応しています。データはブラウザの localStorage に保存します。ブラウザのデータを消すとタスクも消えます。端末間の同期やログイン機能はありません。

## 起動

Python 3 と Node.js 24（テスト用）を使用します。外部パッケージのインストールは不要です。

```sh
cd /workspace/taskmanager
npm start
```

HTTPサーバーはポート3000で起動します。停止は Ctrl+C。クラウド環境からの画面の公開には別途ホスティングが必要です。

## テスト

```sh
npm test
```

ブラウザではタスクを追加し、完了・未完了の絞り込み、再読み込み後の復元、削除を確認してください。

## GitHub Pagesで公開する

GitHubのリポジトリで Settings → Pages を開き、Source を Deploy from a branch、Branch を main、フォルダーを / (root) にして Save を押します。公開処理が完了すると同じ画面にサイトのURLが表示されます。

静的ファイルだけで動作し、サーバーやAPIキーの設定は不要です。公開サイトでもタスクは利用者それぞれのブラウザに保存されます。
