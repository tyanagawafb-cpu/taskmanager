# わたしのタスク

日本語のシンプルなタスク管理アプリ。タスク名・期限・優先度（高・中・低）・進捗（0〜100%）・メモの登録と編集、完了切り替え・削除・絞り込みに対応しています。データはブラウザの localStorage に保存します。ブラウザのデータを消すとタスクも消えます。端末間の同期やログイン機能はありません。

## 起動

Python 3 と Node.js 24（テスト用）を使用します。外部パッケージのインストールは不要です。

```sh
cd /workspace/taskmanager
npm start
```

HTTPサーバーはポート3000で起動します。停止は Ctrl+C。クラウド環境からの画面の公開には別途ホスティングが必要です。

## テスト

```sh
npm test
```

ブラウザではタスクを追加し、完了・未完了の絞り込み、再読み込み後の復元、削除を確認してください。

## GitHub Pagesで公開する

GitHubのリポジトリで Settings → Pages を開き、Source を Deploy from a branch、Branch を main、フォルダーを / (root) にして Save を押します。公開処理が完了すると同じ画面にサイトのURLが表示されます。

静的ファイルだけで動作し、サーバーやAPIキーの設定は不要です。公開サイトでもタスクは利用者それぞれのブラウザに保存されます。

## 日常の使い方

タスク名を入力し、「期限・優先度・進捗・メモ」を開いて詳細を記入します。追加後は「編集」で変更できます。進捗100%は完了となり、完了チェックを外すと進捗0%になります。期限は日付単位で、期限切れの未完了タスクは赤く表示します。通知機能はありません。

定期的に「バックアップを保存」でJSONファイルを保存してください。「バックアップから復元」で追加復元できます。同じIDのタスクは既存の内容を残すため、過去の内容で上書きされません。以前の版で作成したタスクも自動で読み込めます。

バックアップにはタスク名とメモを含む全項目が入ります。ファイルはご自身で保管してください。データの同期には対応していないため、同時に複数タブで編集せず、1つのタブを固定してご利用ください。
